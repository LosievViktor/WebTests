# WebTests

C# code examples for Web UI Automation Tests made with Playwright library.

How to launch?

1. Clone repository
2. Build it via Visual Studio, Rider of other IDE you want.
3. Install Playwright via execution command on Windows PowerShell :

```

cd bin/Debug/net10.0/
./playwright.ps1 install

```

4. Launch tests via IDE or dotnet test command. Please do not forget to use live.runsettings file.
